## 范围与限制

- MuMu 的哔哩哔哩 9.14.0 出现启动 ANR；旧版本模块和未启用模块时也有相同的 Gripper 初始化等待堆栈。清理数据后曾能播放，但冷启动仍复现，因此 **9.14.0 在该模拟器上的播放验收未通过**。换用 9.13.0 后完成 Story 播放界面检查；模拟器解码不能替代真机的画面质量验证。
- 9.13.0 的 Story/普通详情 Activity 未声明 Android 原生画中画支持，未将其记为画中画实测通过。画中画/多窗口暂停策略有单元测试，不能代替所有厂商多窗口实测。
- 本轮没有重新完成 API 101、所有 Android 版本、FusionApp、VPN 检测兼容和 DRM 场景的完整矩阵；YouTube 当时未加载视频内容，不计为播放通过。
- 视频原生比例留边及内嵌黑边可能保留。专项适配只修正已知播放器预留空间，不修改其原生缩放比例策略；未知播放器版本回退。
- 新增作用域通常需要重启目标应用。框架授权、模块加载与实际显示效果是不同状态。
