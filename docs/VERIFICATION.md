# 兼容说明

[简体中文](VERIFICATION.md) | [English](VERIFICATION_EN.md)

- 需要 Android 11 或更新版本及现代 LSPosed / libxposed 兼容框架（API 101 或 102）。
- 作用域授权由框架管理。首次加入作用域后通常需要重启目标应用，保存规则不等于模块已加载。
- 已有自定义、明确关闭和重置结果优先于作用域默认规则。
- 多窗口、画中画和浮动窗口暂停全屏策略；输入法出现时释放导航栏控制。
- 哔哩哔哩播放页优化仅针对已知版本的指定播放页面，可独立关闭。9.14.0 在部分环境中可能出现启动问题，暂不保证兼容；未知版本保留原播放器行为。
- 播放器自身的比例留边、内嵌黑边、DRM 和硬件保护不保证消除。允许截屏及 VPN 检测兼容默认关闭。
